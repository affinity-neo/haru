# 하루

비용을 내지 않고 개인 업무, 일정, 반복 루틴을 관리하는 정적 웹 앱입니다. 정적 호스팅, 브라우저 저장, 선택적 Firebase Spark 동기화를 사용합니다.

## 실행

index.html을 파일로 직접 열지 말고 로컬 또는 무료 HTTPS 정적 호스팅에서 실행합니다. 기본 데이터는 각 브라우저의 로컬 저장소에 남습니다.

## 메뉴와 데이터

- 메뉴는 대시보드, 전체 업무, 오늘 할 일, 언젠가, 캘린더입니다.
- 주간 캘린더가 기본 보기이고 월간 보기로 전환할 수 있습니다. 왼쪽 업무 패널에서 업무를 시간 칸으로 끌어 실행일과 실행 시간을 정합니다. 캘린더에는 오늘 현재 시각 표시가 있습니다.
- 업무는 plannedDate(실행일)와 dueDate(마감일)를 별도로 저장합니다. 업무는 업무 보드와 캘린더에 나타나고, 일정(type: event)은 캘린더에만 나타납니다.
- 루틴(type: routine)은 지정한 요일과 시간에 캘린더에 반복 표시되며 업무 완료 수에는 포함하지 않습니다.
- 카테고리는 업무, 개인, 건강, 가족, 학습, 기타입니다. 날짜 없는 업무는 전체 업무에 계속 남고 언젠가 보기에도 표시됩니다.
- Ctrl+Z 또는 ⌘Z로 앱의 최근 변경을 되돌립니다. 최대 50개 변경을 이 브라우저에서 기억합니다.
- 자연어 날짜·시간·기간 파싱은 로컬 규칙으로 처리합니다. 음성 입력은 브라우저 Web Speech API와 마이크 권한이 필요합니다.
- 기기 내 스마트 일정 추천은 우선순위, 예상 시간, 기존 일정의 빈 시간을 기준으로 14일 범위에 계획을 배치합니다. 외부 AI 호출은 없습니다.

## Firebase Spark 동기화

1. Firebase Console에서 프로젝트와 웹 앱을 만듭니다. Spark 무료 요금제를 유지하고 결제 계정을 연결하지 마세요.
2. 이메일/비밀번호 로그인을 켜고 Firestore를 만든 뒤 firestore.rules를 게시합니다.
3. 앱의 동기화 설정에 Firebase 웹 앱 키와 이메일 계정을 입력합니다.

Spark 사용량 한도에 도달하면 동기화가 제한되고 로컬 저장은 계속됩니다. 사용량 한도를 늘리기 위해 유료 요금제로 바꾸지 마세요.

## Google Calendar 선택 연결

앱의 캘린더에서 Google 연결을 누르면 웹 OAuth Client ID를 입력할 수 있습니다. 이 연결은 기본 캘린더의 앞으로 60일 일정을 수동으로 가져오며, 개별 일정을 Google Calendar로 내보낼 수 있습니다. 자동 양방향 동기화는 제공하지 않습니다. 인증 토큰은 메모리에만 두고 Client ID만 현재 브라우저에 저장합니다.

Google Cloud에서 Calendar API, OAuth 동의 화면, 웹 애플리케이션 Client ID를 설정하고 승인된 JavaScript 출처에 배포 주소를 추가해야 합니다. 앱은 calendar.events.owned 범위만 요청합니다. 비용 0원을 유지하려면 Google Cloud 결제 계정을 연결하지 마세요. 한도 초과 요청은 실패하도록 두고 결제를 활성화하지 않습니다. Google은 일반 Calendar API 사용을 추가 비용 없이 제공하되 2026년 후반 한도 초과 과금 정책을 도입할 수 있다고 알렸으므로 할당량도 확인하세요.

## 데이터 구조

- task: 실행일, 마감일, 카테고리, 우선순위, 예상 시간, 완료 상태
- event: 일정 날짜, 시작/종료, 반복, Google 연결 ID
- routine: 반복 요일, 시간, 예상 시간
- Firebase 경로: users/{uid}/haruItemsV1/{itemId}. 삭제는 동기화 전파를 위해 삭제 표시로 기록합니다.
